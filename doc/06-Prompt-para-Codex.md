# Prompt para colar no Codex
Construa a landing page de venda do e-book Pés de Seda usando esta pasta como especificação. Comece pelo arquivo 00 e leia os arquivos 01 a 05 antes de implementar. Inspecione o projeto existente e preserve seus padrões compatíveis. Se estiver vazio, adote React com renderização inicial de HTML e backend capaz de receber webhooks, persistir pedidos e proteger o PDF.

Use UI/UX Pro Max para pesquisar hierarquia e acessibilidade. Use o 21st.dev para selecionar referências editoriais e registre as fontes e licenças. Use Framer Motion, pela biblioteca Motion para React, para executar a coreografia descrita no arquivo 03. Siga o design system do arquivo 02. Quero uma página marcante e autoral, com a sensação de folhear um livro de família. Priorize capa, tipografia, história real e uma oferta fácil de localizar. Apresente o resultado em celular e desktop.

Implemente a compra única via API Asaas conforme o arquivo 04, com confirmação por webhook, entrega protegida, recuperação e testes de duplicidade. Use credenciais somente no servidor. Se faltarem preço, imagem autorizada, credenciais ou o PDF revisado, prossiga com a construção e os testes locais, identifique as dependências e mantenha a venda real fechada.

Entregue o código executável, instruções de configuração sem segredos, testes, capturas de celular e desktop, inventário das referências visuais e uma matriz de aceite do arquivo 05. Separe o que foi testado localmente do que foi comprovado no sandbox Asaas. Não declare produção pronta com base em simulação. Não publique comercialmente sem aprovação do titular.

Leia também o AGENTS.md da raiz e execute as etapas de 07-Plano-e-verificacao.md. Atualize os resultados após cada etapa.
